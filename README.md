# Nordic Roast Coffee – Företagswebbplats (Business Website)

🔗 **Live-demo:** [https://marsilakova.github.io/nordic-roast-cofee](https://[github.io](https://marsilakova.github.io/nordic-roast-cofee/))

En modern, stilren och responsiv företagswebbplats för ett specialkafferosteri och kafé i Malmö, skapad med **HTML5, CSS3 och JavaScript**.

## Funktioner
* **Responsiv design:** Fullt anpassad för mobil, surfplatta och dator med en interaktiv hamburgermeny för mindre skärmar.
* **Hero-sektion:** Välkomnande startvy med tydlig typografi och call-to-action-knappar (*Explore Menu* och *Book a Tasting*).
* **Om oss (About):** Presentation av rosteriets historia, filosofi och hållbarhetsarbete i Malmö.
* **Interaktiv meny med kategorifiltrering:** Möjlighet att filtrera utbudet dynamiskt (*All*, *Coffee Bar*, *Roasted Beans*, *Fika & Bakery*) med JavaScript.
* **Galleri:** Visuell presentation av kaféets atmosfär, baristahantverk och nyrostade kaffebönor.
* **Kontakt & Bordsbokning:** Öppettider, adress i Malmö samt ett validerat kontakt- och bokningsformulär med direkt bekräftelse till användaren.

## Använda tekniker
* **HTML5** (semantisk och tillgänglig struktur)
* **CSS3** (CSS Grid, Flexbox, CSS-variabler och responsiva media queries)
* **JavaScript (ES6+)** (DOM-manipulering, interaktiv filtrering och formulärhantering)

## Projektstruktur
```text
nordic-roast-coffee/
├── index.html      # Webbplatsens huvudstruktur och innehåll
├── style.css       # Design, färgsättning och responsiv layout
├── script.js       # Interaktiv menyfiltrering, mobilmeny och formulärlogik
├── images/         # Lokala högupplösta bilder för meny, galleri och banner
└── README.md       # Projektdokumentation
```

## Kör projektet lokalt
1. Klona eller ladda ner detta repository till din dator.
2. Öppna mappen i **Visual Studio Code**.
3. Starta `index.html` med tillägget **Live Server** eller öppna filen direkt i valfri webbläsare.
